# Proposal

## Why

Основа приложения (архив `2026-09-19-add-scale-app-foundation`) проверена только юнит-тестами на эмуляторе весов и запуском на эмуляторе Android без Bluetooth. Протокол восстановлен из декомпилированного APK, поэтому часть деталей — предположения: смысл второго байта батареи, флаг перегруза, поведение bonding на разных телефонах, тайминги CCCD/MTU, реакция весов на `0x1C`/`0x1A`/`0x19`. Их нужно подтвердить на реальных весах, прежде чем считать приложение рабочим.

## What Changes

- Встроенный журнал BLE-обмена для отладочных сборок: фазы подключения, отправленные и принятые кадры в hex, ошибки GATT; экспорт журнала через системное «Поделиться».
- Протокол ручной проверки на реальных весах (чек-лист по моделям и сценариям) с записью результатов в `design.md` этого чейнджа.
- Исправления протокола и таймингов по итогам проверки (дельты к `scale-protocol` и `scale-connection`, если поведение отличается от ожидаемого).

## Impact

- Код: `ble/AndroidBleTransport`, `session/ScaleSession` (точки логирования), новый экран «Журнал» только в debug-сборке.
- Нужны реальные весы (минимум одна модель протокола 2025; по возможности TES08) и Android-телефоны разных производителей (Pixel + один из Samsung/Xiaomi).
