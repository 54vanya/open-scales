# Spec Delta

## MODIFIED Requirements

### Requirement: Декодирование данных весов
Приложение SHALL декодировать payload следующих команд, независимо от типа кадра (весы присылают периодические данные кадрами типа `0x01`, ответы на чтение — `0x02`):
- `0x01` вес: int32 BE вес, int16 BE скорость потока, uint16 BE время таймера в секундах, опционально байт перегруза; делитель 10 для граммов и 100 для унций;
- `0x02` таймер: `1` — идёт, `2` — пауза, `3` — сброшен;
- `0x05` батарея: байт 0 — статус (смысл не подтверждён, в интерфейсе не используется), байт 1 — уровень в процентах;
- `0x06` единицы: `0` — граммы, `1` — унции;
- `0x07` звук: `0/1`;
- `0x0C` имя (UTF-8), `0x10` версия прошивки, `0x12` серийный номер (ASCII, модель может не отвечать);
- `0x13` модель: `TES015` → ESPRO, `TES016` → Basic 3, `TES017` → DOT;
- `0x16` авто-отключение: uint16 BE секунды;
- `0x17` чувствительность: уровень во втором байте (1 — высокая, 2 — средняя, 3 — низкая);
- `0x18` точность: `1` — высокая, `10` — низкая;
- `0x25` яркость: 0..100.

CRC во входящих кадрах MUST NOT проверяться строго: реальные весы DOT присылают нулевой CRC.

#### Scenario: Вес в граммах
- **WHEN** единицы — граммы и приходит кадр `0x01` с весом `0x000004D2`, скоростью `0x0019`, временем `0x000F`
- **THEN** отображается вес 123.4 г, поток 2.5 г/с и время 00:15

#### Scenario: Отрицательный вес
- **WHEN** int32 веса равен `0xFFFFFFF6`
- **THEN** вес декодируется как −1.0 г

#### Scenario: Батарея реальных весов DOT
- **WHEN** приходит `A5 5A 02 05 00 02 03 59 00 00`
- **THEN** уровень батареи равен 89%

#### Scenario: Кадр веса с нулевым CRC
- **WHEN** приходит `A5 5A 01 01 00 09` + 9 байт данных + `00 00`
- **THEN** кадр принимается и вес обновляется
