# Design

## Context

`ScaleDisplay` в `ui/dashboard/DashboardScreen.kt` — карточка из трёх строк:
1. `Metric("Таймер", formatTime(...))`, 32 sp (`DigitsTextStyle`), слева; справа предупреждение о перегрузе.
2. Вес `WeightTextStyle` (88 sp, `tnum`) + единица, по центру; блок занимает всё свободное место (`weight(1f)`).
3. `Metric("Поток", …)` внизу.

`formatTime` (`ui/components/Common.kt`) сейчас даёт `%02d:%02d`.

## Goals / Non-Goals

**Goals:** крупный таймер без «прыжков» при смене числа цифр и без ручных измерений текста.

**Non-Goals:** менять вёрстку веса и потока; адаптивный размер шрифта под узкие экраны (отдельная задача, если понадобится).

## Decisions

### 1. Фиксированная ширина через невидимый «шаблон» в `Box`
```kotlin
Box(contentAlignment = Alignment.CenterEnd) {
    Text("00:00", style = WeightTextStyle, modifier = Modifier.alpha(0f))      // задаёт ширину
    Text(formatTime(seconds), style = WeightTextStyle, maxLines = 1)           // прижат вправо
}
```
Сам `Box` стоит по центру карточки. Ширину задаёт реальный шрифт на реальном размере: не нужно ни `TextMeasurer`, ни угадывания коэффициентов, а цифры табличные (`tnum`), так что «00:00» — самая широкая строка.
*Альтернатива:* `rememberTextMeasurer()` + `Modifier.width(...)` — больше кода при том же результате.

### 2. Раскладка карточки
Вместо верхнего `Metric` делаем колонку: подпись «Таймер» (labelLarge, по центру над блоком) → блок таймера → блок веса. Таймер и вес делят свободную высоту поровну (`weight(1f)` у каждого). Предупреждение о перегрузе остаётся маленькой строкой справа сверху, поток — внизу.
Подпись «Таймер» выравнивается по центру блока таймера, а не по его правому краю.

### 3. Формат
```kotlin
fun formatTime(seconds: Int): String {
    val s = seconds.coerceIn(0, 99 * 60 + 59)
    return "%d:%02d".format(s / 60, s % 60)
}
```
Отрицательные значения → `0:00`. Функцию покрываем юнит-тестом.

## Risks / Trade-offs

- [Высота карточки на маленьких экранах: две строки по 96 sp плюс подписи] → на Pixel 9 Pro XL места с запасом. На экране 640 dp по высоте проверить в превью; если не влезает, уменьшить обе строки общим стилем, а не только таймер.
- [Вес `2000.0 g` на ширине 360 dp уже близок к краю] → риск существовал и раньше, этот чейндж его не ухудшает.
- [Неизвестно, что показывают сами весы после 99:59] → ограничение отображения; проверить на весах в `verify-real-scale-connection`.
