# Proposal

## Why

На телефоне варка по рецепту спотыкалась в нескольких местах:
- тару перед «Старт» приходилось нажимать вручную;
- табло до «Старт» показывало первый шаг и значения, которые ещё ничего не значат;
- после конца времени выход всё равно спрашивал «Завершить варку?»;
- при запоздалом проливе табло показывало только недолитый прошлый шаг, а не сколько налить всего к концу текущего.

## What Changes

- «Старт» тарирует весы. Пролив отсчитывается от первого кадра около нуля после тары, запоздалые кадры со старым весом не считаются проливом. Если тару не приняли, возвращается «Старт» с ошибкой.
- До «Старт» табло пустое, с надписью «Нажмите «Старт»», высота табло та же. Карточки шагов считают налитым ноль: на весах ещё воронка с зерном.
- После конца времени «Стоп» и «назад» закрывают варку без подтверждения.
- Шаг воды на табло — последний начавшийся по времени шаг с целью. Недолитое в прошлых шагах складывается с текущим (цели накопительные).

- `ui/brew/BrewViewModel.kt`: тара по «Старт», ожидание нуля после тары.
- `recipe/PourFocus.kt`: шаг воды только по времени.
- `ui/brew/BrewScreens.kt`: пустое табло до «Старт», ноль в распределении до «Старт».
- `ui/brew/BrewActivity.kt`: выход без подтверждения после конца времени.
- Строки ru/en: «Нажмите «Старт»».
