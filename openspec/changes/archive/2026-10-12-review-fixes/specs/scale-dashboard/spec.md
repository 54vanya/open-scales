# Spec Delta

## ADDED Requirements

### Requirement: Сброс таймера весов без синхронизации
Без синхронизации таймера приложение SHALL помнить, какое состояние таймера оно отправило весам, и отправлять «Сброс» весам, только когда их таймер идёт или показывает ненулевое время. Сброс при уже сброшенном таймере весов MUST NOT отправляться: весы понимают его как тару.

#### Scenario: Сброс сразу после запуска
- **WHEN** пользователь нажал «Старт» и меньше чем через секунду «Сброс»
- **THEN** весам ушли запуск и сброс, таймер весов сброшен

#### Scenario: Повторный сброс
- **WHEN** подключились к весам с идущим таймером, пользователь поставил паузу, нажал «Сброс» и ещё раз «Сброс»
- **THEN** второй сброс весам не уходит, вес на весах не обнуляется
