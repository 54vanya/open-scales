# Design

## Context

- `SettingsActivity`/`SettingsScreen` показывают раздел «Приложение» и, если выбраны весы (`state.address != null`), разделы «Устройство», «Взвешивание», «Действия». Заголовок — «Настройки весов» или «Настройки». При открытии и при `isReady` вызывается `viewModel.loadSettings()`.
- `ScanActivity`/`ScanScreen` — поиск: при открытии и на `ON_RESUME` запускают сканирование на 30 с, на `ON_PAUSE` останавливают. Раздел «Мои весы» — одна строка `SavedDevice`, нажатие → `connect`, после READY выбранных весов экран закрывается.
- Запомнить можно одни весы (`SavedDeviceStore.device: Flow<SavedDevice?>`).
- Главный экран: в верхней панели `BluetoothSearching` → `ScanActivity`, `Settings` → `SettingsActivity`.
- Обсуждение и отвергнутые варианты — в исследовании перед этим изменением: карточка прямо на экране «Весы» (длинно, поиск мешает настройкам), шестерёнка главного экрана с вложенным пунктом «Весы» (пользователь выбрал шестерёнку в строке весов, как в системном Bluetooth).

## Goals / Non-Goals

**Goals:** экран настроек приложения без условных разделов; всё о конкретных весах — рядом с ними; раскладка, которая не растёт с числом весов.

**Non-Goals:**
- несколько запомненных весов (хранилище списка, правило авто-подключения, «Забыть» из меню строки) — отдельное изменение;
- быстрый переключатель единиц на главном экране (пользователь переключает редко, минус с лишним нажатием принят).

## Decisions

### Карточка весов — отдельная Activity

`ScaleDetailsActivity` + `ScaleDetailsScreen`: разделы «Устройство», «Взвешивание», «Действия» переносятся из `SettingsScreen` как есть (строки, диалоги подтверждения и переименования, `SettingsActions` для весов). Отдельная Activity — как остальные экраны проекта, чтобы системный жест «назад» работал без своей анимации. Карточка берёт состояние из общей `ScaleViewModel`; адрес весов приходит в `Intent` — задел под несколько весов, сейчас он совпадает с запомненными.

Состояния карточки:
- весы с этим адресом подключены (`state.isReady && state.address == address`) — все разделы, `loadSettings()` при открытии и при переходе в READY;
- не подключены — сведения из `SavedDevice` (имя, модель, адрес), кнопки «Подключить» (как «Подключить» на главном экране) и «Забыть устройство»; «Взвешивание» и остальные действия скрыты;
- подключаются — как «не подключены», но вместо «Подключить» индикатор и фаза.

«Забыть устройство» закрывает карточку, как сейчас закрывает экран настроек; после «Сброса к заводским настройкам» весы сами рвут связь, карточка остаётся и показывает неподключённые весы — как раньше экран настроек.

`SettingsScreen` оставляет только раздел «Приложение», заголовок всегда «Настройки»; ранний выход `if (!hasScale) return@LazyColumn` и строка «Подключите весы, чтобы изменить настройки» уходят (в карточке она тоже не нужна: для неподключённых весов разделы с настройками просто скрыты).

### Экран «Весы»

- Заголовок `scan_title` → «Весы»/«Scales»; строки `scan_subtitle_*` остаются подзаголовком состояния поиска.
- Строка «Мои весы»: `trailingContent` — `IconButton` с шестерёнкой (описание для диктора «Настройки весов <имя>»). Подпись: подключены — «Подключено · 75 %», подключаются — фаза, иначе — модель и сигнал, если весы видны в эфире, или «Не в сети».
- Нажатие на строку: подключены → открыть карточку; иначе → `connect` (как сейчас). Возврат на главный экран после READY выбранных весов остаётся только для подключения из «Найденные» — подключение запомненных весов с этого экрана оставляет пользователя на экране (он может хотеть открыть карточку); *альтернатива* — закрывать и здесь, отвергнута: пользователь пришёл на экран «Весы», а не на главный.
- Автозапуск поиска на `LaunchedEffect`/`ON_RESUME` — только при `!state.isReady`. Кнопка «Искать» (существующий FAB «Искать снова»/«Остановить») работает всегда.

### Верхняя панель главного экрана

`Icons.AutoMirrored.Rounded.BluetoothSearching` → `Icons.Rounded.Scale`, описание «Весы»/«Scales». Шестерёнка — «Настройки»/«Settings» (сейчас описание «Настройки весов», оно меняется вместе со смыслом).

## Risks / Trade-offs

- [Настройки весов дальше на одно нажатие и их сложнее найти по привычке] → принято пользователем; баннер «Найти весы» и иконка весов ведут на экран «Весы».
- [Единицы г/унции тоже глубже] → принято: переключают редко.
- [Пересечение с `add-english-localization` и `add-theme-setting` по `SettingsScreen` и строкам] → реализовывать после их архивации; дельта «Сервисные действия» уже с формулировкой из локализации.
- [Экран «Весы» сложнее экрана поиска] → состояния строки покрываются превью; логика «нажатие по состоянию» и «автозапуск поиска» — чистые функции с юнит-тестами.
