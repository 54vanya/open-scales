# Proposal

## Why

Многие подписи интерфейса звучат отстранённо: внутренние термины вместо слов человека («Рубеж воды», «Подпись», «Доза по умолчанию», «Настройка приёма данных…»), описание механики вместо пользы («Крупно — время до конца шага», «Синхронизировать таймер с весами»), общие ошибки вместо конкретных («Заполните поле», «Должно быть больше нуля», кнопка «Подтвердить»). Шаг «Тара» к тому же единственный назван существительным, хотя остальные шаги — глаголы («Налейте», «Подождите»).

## What Changes

Только тексты: поведение, раскладка и формат рецепта не меняются. Подписи, процитированные в спеках:

- Редактор: «Доза по умолчанию» → «Кофе», «Комментарий» → «Как делать» (эти два поля — в «Раскрытии карточек», которое меняет `recipe-editor-convenience`), окно выхода «Отменить изменения?» / «Продолжить редактирование» / «Отменить изменения» → «Не сохранять изменения?» / «Вернуться» / «Не сохранять».
- Варка: «Доза в рецепте 15 г · Вода 250 г» → «По рецепту 15 г кофе на 250 г воды», кнопка ожидания «Начните пролив» → «Лейте, когда готовы», подпись «осталось из 150 г» → «осталось до 150 г», настройка «Вес в шагах рецепта» («Осталось налить» / «Налито из цели») → «Что показывать у шагов» («Сколько осталось» / «Сколько налито»).
- Настройки: «Не гасить экран на главном экране» → «Не гасить экран, пока открыты весы», «Синхронизировать таймер с весами» → «Таймер с весов», «Собственные цвета приложения» → «Цвета приложения», «Срабатывание кнопок» → «Когда срабатывают кнопки», «Забыть устройство» → «Забыть весы»; кнопка в окнах подтверждения называет действие («Сбросить», «Забыть») вместо «Подтвердить».

Не процитированные в спеках: подсказки полей и настроек, ошибки редактора по каждому полю («Нужно название», «Как называется шаг?», «Не может быть ноль», «Выше уже 150 г — здесь не меньше»), внутренние фазы подключения показываются как «Подключение…», ошибки подключения и команд проще («Связь оборвалась при подключении», «Не удалось узнать модель весов»), ограничение имени весов — в буквах, а не байтах. Английские строки — тем же проходом.

Подписи, которые вводят `recipe-editor-convenience` и `recipe-tare-step` («Рубеж воды», «Подпись», «Действие», «Дублировать», название шага «Тара»), поправлены прямо в этих чейнджах: «Воды к концу шага», «Заметка», «Другое действие», «Повторить», «Обнулите весы».

Внутреннее имя признака шага в спеках («крупно — время до конца шага») не меняется: пользователь его не видит.

### New Capabilities

### Modified Capabilities
- `app-theme`: «Цвета приложения» (название переключателя).
- `recipe-brewing`: «Взвешивание зерна», «Запуск по началу пролива», «Распределение налитой воды», «Табло пролива» (подписи варки и настройки вида значений).
- `recipe-editor`: «Сохранение и отмена» (окно выхода).
- `scale-connection`: «Забыть устройство» (название действия).
- `scale-dashboard`: «Кнопки управления», «Экран не гаснет на главном экране», «Источник времени таймера», «Подхват таймера весов при подключении» (названия настроек).
- `scale-settings`: «Сервисные действия» (название действия, кнопка подтверждения), «Карточка весов».

## Impact

- `res/values/strings.xml`, `res/values-ru/strings.xml`: тексты; новые строки для ошибок по полям и кнопок подтверждения.
- `ui/editor/RecipeEditorScreen.kt`: текст ошибки «пусто» выбирается по полю.
- `ui/scale/ScaleDetailsScreen.kt`: кнопка подтверждения по действию.
- Скриншот-тесты: перезаписываются эталоны, где видны изменённые подписи.
