# Design

## Context

Табло (`PourBoard`) уже знает текущий по времени шаг и остаток в нём: он показан мелко справа вверху. Модель шага — `RecipeItem.Step(title, durationS, note, targetG)`. JSON читается с `ignoreUnknownKeys`, а поля со значением по умолчанию kotlinx.serialization не пишет.

## Goals / Non-Goals

**Goals:**
- Одно поле в модели и формате, без новой версии формата.
- Табло переключается между «водой» и «временем» по признаку текущего шага.

**Non-Goals:**
- Автоматически выводить признак из того, есть ли у шага цель воды. У пуровера после цветения и в «Подождите» смотрят на воду и слив, поэтому признак ставит автор рецепта.
- Новые звуковые сигналы: смена шага уже подаёт сигнал.

## Decisions

### Поле `showTime` в шаге

`RecipeItem.Step(..., showTime: Boolean = false)`, `DraftItem.Step.showTime`, `ItemDto.Step.showTime = false`. В JSON поле пишется только при `true`, потому что kotlinx.serialization не кодирует значения по умолчанию. Старые документы читаются с `false`. Помощник `step(...)` в `BuiltInRecipes` получает параметр `time = true` для шагов аэропрессов.

### Табло: ветка «время»

В `PourBoard`: если `current != null`, шаг с `showTime` и `ui.started`, то:
- крупное число — `formatTime(remainingIn(current, seconds))` стилем показаний веса. Акцентный цвет при остатке ≤ 5 с;
- подпись под ним — название следующего шага (`RecipeItem.Step` после текущего) или «до конца»;
- мелкая строка — «всего … · поток», как сейчас;
- правый верхний угол — значение шага воды из `PourFocus` по настройке и с цветом состояния (по просьбе с телефона вместо «время / длительность»: видно, попал ли прошлый пролив в рубеж); мелкая строка — общий вес и поток.

В ожидании пролива (ARMED), если у первого шага стоит признак, крупно показывается его полная длительность. До «Старт» табло пустое, как было. Высота табло не меняется: используется тот же каркас, меняется только содержимое строк.

### Редактор

В `ExpandedItem` для шага — строка с `Switch` и подписью после поля «Комментарий». У свёрнутой `StepCard` — небольшая иконка `Timer` рядом со временем (новый параметр `showsTime`).

## Risks / Trade-offs

- [Крупное «м:сс» уже, чем вес «250.0»] → тот же `TextAutoSize`, что у веса: число не обрежется.
- [В альбомной раскладке табло узкое] → проверить на эмуляторе поворотом.
