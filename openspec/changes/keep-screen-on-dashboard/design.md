# Design

## Context

Главный экран — `MainActivity` + `DashboardScreen`. Настройки приложения уже есть: `AppSettings` (звук кнопок, нота, режим срабатывания) в DataStore `scale`, раздел «Приложение» в `SettingsScreen` доступен без весов.

## Goals / Non-Goals

**Goals:** удержание строго на время показа главного экрана, без разрешений и без wake lock'ов, которые надо освобождать вручную.

**Non-Goals:** включать экран при событиях от весов (например, на старте таймера); удерживать экран на экранах поиска и настроек; удержание при свёрнутом приложении.

## Decisions

- **`View.keepScreenOn` из Compose**, а не `WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON` вручную:
  ```kotlin
  val view = LocalView.current
  DisposableEffect(keepOn) {
      view.keepScreenOn = keepOn
      onDispose { view.keepScreenOn = false }
  }
  ```
  Флаг живёт ровно столько, сколько композиция главного экрана: при уходе с экрана и уничтожении Activity он снимается сам. Система сама перестаёт учитывать его, когда окно не на переднем плане, поэтому отдельная обработка `onStop` не нужна.
  *Альтернатива:* `PowerManager.WakeLock` — требует ручного освобождения и разрешения `WAKE_LOCK`, легко «подвесить» экран при падении.
- **Настройка** `AppSettings.keepScreenOn` (по умолчанию `true`), ключ DataStore `keep_screen_on`, рядом с остальными настройками приложения; в UI — переключатель в разделе «Приложение» под «Срабатыванием кнопок».

## Risks / Trade-offs

- [Расход батареи, если оставить главный экран открытым надолго] → осознанно; выключается настройкой, а уход с экрана или сворачивание снимают удержание.
- [Выгорание OLED при статичной картинке] → значения веса и таймера меняются, интерфейс не полностью статичен; риск сопоставим с любым таймером на экране.
