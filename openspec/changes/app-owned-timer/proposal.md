# Proposal

## Why

Сейчас время таймера для весов протокола 2025 приходит из кадров весов: приложение только отображает то,
что досчитали весы. Отсюда три проблемы. Первая — задержка: состояние кнопки переключается сразу, а цифры
ждут BLE-обмена. Вторая — точность: весы присылают целые секунды, своя база времени дала бы десятые и не
зависела бы от доставки кадров. Третья — таймером нельзя пользоваться без весов, хотя секундомеру весы не нужны.

Ведение времени в приложении снимает всё это сразу и открывает дорогу к тому, что на весах не выразить:
автостарт по началу пролива, фазы, целевое время. У имеющихся моделей (DOT, Basic 3, ESPRO) нет экрана,
поэтому собственный таймер весов пользователю не виден — но модели с экраном возможны, и для них показ
времени именно с весов должен оставаться доступным.

## What Changes

- Время таймера по умолчанию ведёт приложение: монотонные часы телефона, не зависящие от кадров весов.
- Новая настройка приложения «Синхронизировать таймер с весами» в разделе «Приложение», выключена по умолчанию.
  Включённая — время и состояние таймера берутся с весов, как сейчас (для моделей с собственным экраном).
  Выключенная — кадры таймера с весов игнорируются полностью.
- Кнопки «Старт/Пауза» и «Сброс» становятся активны всегда, в том числе без подключённых весов. «Тара»
  по-прежнему требует состояния READY.
- Команды таймера (`0x02`) продолжают уходить на весы в обоих режимах, пока есть подключение: идущий таймер
  удерживает весы от авто-отключения посреди долгого пролива. В режиме без синхронизации отправка
  best-effort — на показания приложения её результат не влияет.
- Отсчёт продолжается при обрыве связи и при переходе между экранами приложения.
- Локальный таймер для TES08 перестаёт быть отдельной веткой: теперь это общий путь для всех моделей.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `scale-dashboard`: источником времени становится приложение (с настройкой синхронизации); кнопки таймера
  работают без подключения; «Старт/Пауза» больше не откатывается по отказу весов в режиме без синхронизации.
- `button-sound`: кнопки таймера звучат и без подключённых весов, потому что перестают быть неактивными.

## Impact

- `session/ScaleRepository` — часы таймера живут здесь, чтобы переживать закрытие экранов и отсутствие сессии.
- `session/ScaleSession` — перестаёт быть источником времени для протокола 2025; `runLegacyTimer` уходит в общий путь.
- `data/AppSettingsStore` — новый ключ настройки синхронизации.
- `ui/dashboard/DashboardScreen`, `ui/settings/SettingsScreen`, `ui/ScaleViewModel` — доступность кнопок и новый пункт настроек.
- Тесты `session` на `FakeBleTransport` — сценарии таймера без сессии и с включённой синхронизацией.
